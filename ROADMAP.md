# 🗺️ Roadmap — ClaritySort

Здесь описаны планы по развитию проекта. Сроки не жёсткие, приоритеты могут меняться.

## ✅ Реализовано в v1.0.x
- Гибкая сортировка по расширениям и ключевым словам
- GUI на Tkinter с поддержкой двух тем
- Локализация (русский и английский)
- Проверка больших файлов с настраиваемым порогом
- Детальное логирование в JSON
- Готовый EXE для Windows

## 🐞 Известные ограничения (текущая версия)
- Прокрутка колёсиком в списках настроек (4 строки вместо 1)
- Длинные названия категорий обрезаются
- Избыточное логирование при неизменных настройках безопасности
- Стандартная иконка в некоторых диалогах
- Размытость на экранах с высоким DPI
- Позиционирование окна настроек на нескольких мониторах

*(Эти проблемы не критичны, будут исправлены в следующих обновлениях)*
